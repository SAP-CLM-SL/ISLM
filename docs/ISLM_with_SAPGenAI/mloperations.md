# Operate the Intelligent Scenario

Once the Intelligent Scenario is published, the Intelligent Scenario Management app helps you to deploy and activate the model for productive usage.
In this section, you will use the **Intelligent Scenario Management app** to perform operations on your Intelligent Scenario.

1. Open the Fiori Launchpad and launch the **Intelligent Scenario Management** app under the **Analytics** tab. Please refer to the cheat sheet for guidance.
   ![](./images/Management.png) <br>
   
2. Search the **Gen AI** scenario created by you and navigate to the details page by clicking the **'>'** icon.
   ![](./images/Mpage.png) <br>
   
3. Navigate to details page by clicking the **'>'** icon
   ![](./images/ModelView.png) <br>
   
4. As GenAI is a pre-trained model and the reuse connectivity is already configured in the system, the synchronization has completed successfully using the default training setup. Select the default training and click the **Deploy** Button.
   ![](./images/Deploy.png) <br>
   
5. **Deployment** makes the configured AI model or scenario available for use. Click the **Deploy and Monitor** button.
   ![](./images/DeployMonitor.png) <br>
   
6. A new Deployment is **Scheduled**.
   ![](./images/Scheduled.png) <br>
   
7. Deployment is deployed immediately as it's **Shared deployment**.
   ![](./images/Deployed.png) <br>
   
8. **Activate** enables the deployed version so that it can be used for execution. After the required configuration is completed and deployed, the scenario can be activated so that applications can call it and receive responses.<br>
Select the Deployment and click on **Activate** button and choose **For All** option.
   ![](./images/Activate.png) <br>
   
9. In the dialog Activate for All Users, choose **Activate For All** button.
   ![](./images/ActiveForAll.png)

Well done, you just Used **Intelligent Scenario Management** app to deploy and activate the llm model.
